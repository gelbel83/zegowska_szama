## Aplikacja Webowa - ZEGOWSKA SZAMA
Strona sklepiku szkolnego zegu. Projekt realizowany w ramach zlecenia użytkownika mający na celu stworzenie platformy webowej dla uczniów, nauczycieli oraz zespołu prowadzącego szkolny sklepik.

---

## O Projekcie
Aplikacja ZEGOWSKA SZAMA umożliwia użytkownikom wygodne przeglądanie asortymentu, sprawdzanie aktualnych promocji oraz składanie zamówień online z odbiorem osobistym w sklepiku. Z kolei obsługa oraz administratorzy otrzymują zaawansowane narzędzia do zarządzania bazą produktów, zamówieniami i kontami użytkowników.

## Technologia i Architektura
Projekt został wykonany w oparciu o klasyczny, bezpieczny i wydajny stos technologiczny:
* **Backend:** PHP
* **Frontend:** JavaScript + Bootstrap
* **Baza Danych:** MySQL
* **Wersjonowanie:** Git

---

## Główne Funkcjonalności

### 1. Moduł Klienta
* **Rejestracja i Logowanie:** Formularz z walidacją danych. Hasła użytkowników są hashowane. Sesja użytkownika jest podtrzymywana po zalogowaniu.
* **Przeglądanie Produktów:** Dynamiczna lista pobierana z bazy danych. Możliwość filtrowania i szybkiego wyszukiwania za pomocą JavaScript.
* **Strefa Promocji:** Dedykowana, osobna sekcja dostępna wyłącznie dla zalogowanych użytkowników.
* **Koszyk i Zamówienia:** System koszyka realizowany w JavaScript. Możliwość swobodnego dodawania/usuwania artykułów i składania zamówienia.

### 2. Panel Administracyjny
Dostęp do panelu jest ograniczony.
* **Zarządzanie Użytkownikami:** Wyświetlanie pełnej listy użytkowników, możliwość usuwania kont oraz nadawania i odbierania uprawnień administratora.
* **Zarządzanie Produktami:** Formularze dodawania, edycji oraz usuwania produktów z bazy.
* **Zarządzanie Zamówieniami:** Podgląd spisu zamówień wraz z ich szczegółami oraz opcja modyfikacji statusu realizacji zamówienia.
